Install Atrium Instantly

Get up and running with a single copy-paste command. The native installer automatically registers the MCP configurations in Claude, Cursor, Cline, and Continue.

🍎 macOS & 🐧 Linux (Bash)

curl -fsSL https://raw.githubusercontent.com/MrDawell/atrium/main/install.sh | bash

❖ Windows (PowerShell)

irm https://raw.githubusercontent.com/MrDawell/atrium/main/install.ps1 | iex
